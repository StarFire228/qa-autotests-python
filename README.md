# QA Autotests Python

Учебный проект по автоматизации тестирования на Python.
Я перехожу из ручного тестирования (3 года опыта 60% на 40%) в автоматизацию,
здесь собираю практику по pytest и API-тестированию.

## Что внутри

- `price.py` — функция расчёта стоимости заказа со скидкой и валидацией входных данных
- `test_price.py` — тесты для неё: параметризация, граничные значения, негативные сценарии
- `test_api.py` — API-тесты для учебного сервиса JSONPlaceholder:
  GET и POST запросы, проверка статус-кодов, структуры ответа и вложенных данных, фикстуры

## Стек

- Python 3.14
- pytest
- requests

## Как запустить

```
pip install -r requirements.txt
pytest -v
```

## Планы

- UI-автотесты на Playwright
- Запуск тестов в CI (GitHub Actions)
- Отчёты Allure
